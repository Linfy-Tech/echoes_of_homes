# M0 ASR benchmark report — 2026-11-08

## Decision status

**Blocked for accuracy selection.** The repository contains no real,
consented isiXhosa audio or gold transcripts, and no access-controlled
evaluation-store credentials were supplied. The only fixture created in this
slice is synthetic text for testing the evaluator; it is explicitly not
benchmark evidence.

This means M0-AC2 is not met and ADR-005 cannot make a final provider/model
selection. No paid provider calls were made.

## Repository finding

`tests/evaluation/README.md` describes a separate access-controlled store, but
the checkout contains only that README. There are no audio files, gold
transcripts, normalisation scripts, provider-response fixtures, or benchmark
results. `packages/ai-providers` is also only a package scaffold. The existing
`pnpm eval:asr --fixtures` command does not exist in `package.json`; this slice
adds the offline `eval:asr` entry point and a dependency-free evaluator.

## Offline evaluator

The evaluator is `scripts/asr-eval.mjs`. It consumes a JSON manifest with a
dataset version, reference transcript per `sampleId`, and candidate outputs
with latency, duration, and optional published `costUsdPerMinute`.

It applies Unicode NFC, lowercase, punctuation/symbol removal, whitespace
collapse, then computes aggregate WER and whitespace-free CER. It also emits
recording-level bootstrap 95% intervals using a fixed seed, median latency,
audio minutes, and cost. The synthetic fixture and tests prove the evaluator's
math and report path only.

Run once real fixtures are available:

```sh
node scripts/asr-eval.mjs path/to/manifest.json tests/evaluation/reports/asr-YYYY-MM-DD.md
```

The manifest must remain outside Git if it contains consented audio metadata or
gold text covered by restricted research consent. Only hashes, aggregate
results, and approved snippets belong in this repository.

## Compliant collection plan

1. Obtain counsel-reviewed research consent separate from product consent. It
   must explain computer-program evaluation, provider processing, who may
   listen, retention, withdrawal, cross-border processing, payment, and
   comparison across vendors. The pending isiXhosa consent-script work must be
   completed and reviewed by two fluent speakers; it is not silently reused as
   research consent.
2. Recruit 20–25 speakers, at least 50% aged 60+, across at least three
   regional varieties plus Cape Town urban speech. Record 30–50 sessions,
   5–30 minutes each, totalling 6–10 hours. Include quiet rooms, TV/radio,
   multiple speakers, outdoor conditions, phone microphones, natural pacing,
   code-switching, names, kinship terms, and (only where explicitly allowed)
   praise poetry/recitation.
3. Store originals and annotations in a separate EU-region, access-controlled
   evaluation project. Keep an access ledger, encrypted backups, withdrawal
   deletion path, retention deadline, and provider-export log. Do not mix this
   data with product stories or commit it to Git.
4. Have two fluent annotators independently transcribe each recording using
   `docs/ASR_BENCHMARK.md`; adjudicate disagreements, tag entities,
   code-switches, overlap, inaudible spans, numbers, and dates; record
   inter-annotator CER and segment timestamps.
5. Freeze a manifest containing dataset hash, split (`dev`/`test`), speaker and
   condition strata, consent version, and annotation version. Tune thresholds
   only on dev; run each candidate once on held-out test for selection.

## Cost ceiling

No spend occurred. The proposed first held-out run is 6 hours (360 minutes)
per candidate, with five candidates at most. Known published API subtotal for
Google V2 standard plus OpenAI `gpt-transcribe` would be:

```text
Google: 360 × $0.016 = $5.76
OpenAI: 360 × $0.0045 = $1.62
Known subtotal: $7.38
```

Azure's applicable plan price, Lelapa's paid plan, Meta GPU hosting, and
Sunbird hosted API price are not fixed by the public pages above, so the full
six-candidate estimate is **$7.38 + Azure quote + Meta GPU estimate + Sunbird
quote**, excluding storage and egress. Lelapa publishes subscription prices
but not an audio-minute rate; Sunbird's API pricing is genuinely unlisted in
the public documentation. A second run with keyword hints would double the
relevant hosted minutes. No paid call may run until this ceiling is updated
with current quotes and the product owner explicitly approves it.

Trivial connectivity checks against provider endpoints are deferred; if
approved later, they must use a synthetic or public-domain non-isiXhosa clip,
record exact duration/provider response/charge, and must not be described as
isiXhosa benchmark evidence.

## Accuracy and latency

There are no measured WER, CER, entity, hallucination, uncertainty-recall,
review-effort, or provider-latency results. Reporting estimates or vendor
figures as Echoes results would be invalid.

## M4 implications

M4 cannot safely select a production ASR provider yet. M4 may begin only as a
provider-neutral pipeline spike using the fake adapter and recorded response
fixtures, or with a clearly labelled provisional provider behind configuration
and a mandatory re-evaluation gate. It must not expose a provider choice as
final or tune uncertainty thresholds on synthetic speech. Before production
ASR, collect the consented set, run dev/test evaluation, complete privacy and
licence review, and update ADR-005.
