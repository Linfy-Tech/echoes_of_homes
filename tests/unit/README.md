# tests/unit

Cross-package unit tests that don't belong to a single package (most unit tests live next to source as `*.test.ts`). Examples: enum parity between `packages/shared-types` and migration CHECK constraints; policy table ↔ `docs/CONSENT_AND_OWNERSHIP.md` §5 parity; canonical-hash stability. See `docs/TEST_STRATEGY.md` §2–3.
