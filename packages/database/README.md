# packages/database

Drizzle schema, SQL migrations, repositories, and **domain services** (`src/domain/`) shared by api and worker (ADR-008).

- Schema and constraints exactly as `docs/DATA_MODEL.md`; enum values exactly as `docs/MACHINE.md`.
- Migrations: generated by drizzle-kit, reviewed and edited by hand, committed as SQL, forward-only; triggers/privileges/partial indexes written explicitly.
- Domain services own transactions: load `FOR UPDATE` → `assertCan` → guards → versioned write → audit event → `enqueueJob` (`docs/SYSTEM_DESIGN.md` §1, §4.1).
- `enqueueJob(tx, …)` inserts `processing_jobs` and calls `graphile_worker.add_job` in the same transaction.
- Field encryption helpers for 🔒 columns live here (keyring from config).

Must not import provider SDKs or HTTP frameworks.
